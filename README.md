# BloodHelper: правила модулей

Публичные правила для BloodHelper 1.1.13 и новее. Старые JAR не читают этот файл.

## Как выключить функцию

1. Откройте [policy.json](policy.json), нажмите карандаш (Edit).
2. Найдите модуль в `modules`, поставьте `"allowed": false` или `"enabled": false`.
3. Увеличьте `revision` на 1. Остальные поля и идентификаторы оставьте на месте.
4. Нажмите **Commit changes** в ветку **main**.

Чтобы снова разрешить модуль, верните оба значения в `true`. Клиент восстановит личный выбор игрока. Правила не включают функции, которые игрок сам выключил, и не стирают его конфиги.

Для общего Safe Mode поставьте `"safeMode": true`. Этот режим отключает `legendaryVisuals`, `opponentCooldowns` и `betterNameVisibility`. Личный `serverSafeMode` в client.json всегда имеет приоритет: удалённые правила его не снимают.

Все 42 идентификатора перечислены в policy.json. Для ресурспака используется `resourcePack`, для боевого HUD — `combatHud` (включая таймер и индикатор поножей), для AI — `aiAssistant`. Объекты должны содержать именно булевы `allowed` и `enabled`.

## Если GitHub недоступен

До первой успешной проверки и после ошибки сети, HTTP, JSON или проверки формата применяется встроенный Safe Mode. Последняя успешная разрешающая политика не используется как запасной вариант. Проверка — при запуске и каждые 5 минут; после ошибки повтор через минуту. Срок действия загруженной политики в памяти — максимум 6 минут без успешной проверки. Поэтому обрыв сети определяется на очередном запросе, а не мгновенно. GitHub также может кешировать raw-файл несколько минут.

## Уведомления об обновлении

В `updates` укажите последнюю **опубликованную** версию BloodHelper отдельно для каждой версии Minecraft, например `"1.21.11": "1.1.13"`. Не указывайте ещё не выпущенную сборку. Клиент сравнивает три числа версии и показывает сообщение в меню. Кнопка в «О моде» открывает фиксированную официальную страницу Modrinth с подтверждением Minecraft. Автозагрузки и запуска JAR нет.

## Что передаётся

Клиент запрашивает один публичный HTTPS-файл на raw.githubusercontent.com без авторизации. Сервер игры, ник, чат, координаты и конфиги в запрос не включаются. GitHub получает обычные сетевые сведения запроса, включая IP. Лимит ответа 32 КиБ; редиректы запрещены. Здесь нет удалённого кода, команд, путей загрузки или персональных правил.

Неверный JSON, отсутствующий/неизвестный модуль, строка вместо boolean или неподдерживаемая схема включают Safe Mode. Старшую revision в рамках текущего запуска нельзя заменить меньшей. Это не античит и не принудительная защита от изменения самого JAR.

Этот репозиторий содержит только публичную политику и документацию. Исходники клиента, токены, модели AI и приватные конфиги сюда не загружаются.
